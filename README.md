QuantQuest was developed with assistance from ChatGPT and Cursor.

I began the project from my own interest in investing and quantitative strategies, including trading-strategy code I worked on before turning the project into a mobile app. When I moved into areas of development that were new to me, I used AI as both a coding and learning tool.

I used AI to:

help adapt existing ideas and code into React Native/TypeScript/JavaScript;
generate and revise portions of application code;
troubleshoot errors using code, error messages, and test results I provided;
explain unfamiliar code and development concepts;
help connect the mobile interface, database, authentication, market-data pipeline, and server-side trade logic; and
guide me through parts of mobile development and Apple app preparation that I had not done before.
My process was iterative: I described what I wanted to build, tested the resulting implementation in QuantQuest, reported what worked or failed, and continued revising it. I made the decisions about the app's concept, features, user experience, educational purpose, and overall direction.

I also used official documentation from Expo/React Native, Supabase, Cloudflare, Twelve Data, and Apple while configuring and understanding those services.

Some of my original code from when I first started coding in python is in here too.
